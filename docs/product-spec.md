# プロダクト仕様書 — HTML仕様書ビューワー

## 概要

任意ディレクトリ内の静的HTML仕様書を、PowerPointのようにページ単位で閲覧・検索できるElectronデスクトップアプリ。ローカルフォルダを開くだけで、目次に基づくページ一覧・横断検索・集中閲覧を提供する。

## ユーザー価値

- **仕様書を「1冊のデッキ」として読める**: 目次（`index.html`）に載ったリンクをページとして並べ、前後移動や一覧から素早くジャンプできる。
- **全文検索で目的の記述に到達できる**: 全ページを横断してヒットを一覧し、ページ内でもハイライト付きで前後移動できる。
- **既存HTML資産をそのまま使える**: 変換やサーバー構築なし。フォルダを選ぶだけで閲覧開始。
- **安全なローカル閲覧**: 選択フォルダ外へのアクセスを拒否し、外部URLは既定ブラウザで開く。

## 対象ユーザー

- 社内・プロジェクト内のHTML形式仕様書を読むエンジニア、PM、レビュアー
- 複数HTMLに分割されたドキュメントを、プレゼン資料のように順番に確認したい人
- ローカルに置いた仕様書からキーワードで該当箇所を探したい人

## 主要体験

### 1. フォルダを開いて読む

1. アプリ起動後、ディレクトリ選択ダイアログで仕様書フォルダを選ぶ。
2. 目次の1ページ目が中央ペインに表示される。
3. 左ペインのページ一覧から任意ページへ移動。`←` / `→` で前後ページへ。

### 2. 目次とアンカーでナビゲート

- ページ一覧は番号・タイトル・ファイルパスを表示（サムネイルなし）。
- `page.html#section` は同一ページに統合し、行を展開してセクション（アンカー）を選べる。
- 無効リンク（ファイルなし・範囲外）はグレーアウト。外部URLは「外部リンク」として別ブラウザで開く。

### 3. 検索して該当箇所へ

1. ツールバーの検索ボックスに語句を入力。
2. 右ペインにページ別ヒット一覧が開く。
3. ヒットを選ぶと該当ページを表示し、ページ内検索でハイライト。
4. 「次へ」「前へ」でドキュメント全体を連続して辿れる。

### 4. 表示を調整する

- ズーム（拡大・縮小・100%リセット）、サイドバー表示切替、集中モードで閲覧に集中できる。
- HTML内の同一仕様書リンクをクリックすると、ビューワー内遷移し左ペインの選択も同期する。

## 情報設計

### 入力単位

| 概念 | 定義 |
|------|------|
| 仕様書（デッキ） | ユーザーが選んだ1フォルダ |
| 目次 | フォルダ直下の `index.html`（ページ一覧には含めない） |
| ページ | 目次に載っている `.html` リンク（アンカーは同一ページの子項目） |
| 検索カタログ | main が構築する、ページ別ヒット件数・抜粋のメモリ上インデックス |

### ページタイトルの決定順

1. 目次リンクテキスト
2. 各HTMLの `<title>`
3. 最初の見出し
4. ファイル名

### 目次がない場合

- `index.html` が無い、または目次リンクが0件のとき、フォルダ配下の `.html` を再帰スキャンし自然順でページ化（`index.html` は除外）。
- **「目次がありません」** の警告を表示する。

### リンク種別

| 種別 | 一覧表示 | 操作 |
|------|----------|------|
| フォルダ内 `.html` | 通常 | ビューワー内で表示 |
| 実ファイルなし | グレーアウト「見つかりません」 | 選択不可 |
| フォルダ外 `.html` | グレーアウト「範囲外」 | 選択不可 |
| `https://` 外部URL | 「外部リンク」 | `shell.openExternal()` |

### UIレイアウト

```
┌─────────────────────────────────────────────────────┐
│ ツールバー（検索・ページ移動・ズーム・表示切替）      │
├──────────┬──────────────────────┬───────────────────┤
│ 左ペイン  │ 中央: BrowserView     │ 右ペイン（検索時） │
│ ページ一覧│ 仕様書HTML表示        │ ヒット一覧         │
└──────────┴──────────────────────┴───────────────────┘
```

## セキュリティ方針

- **ローカルHTTPサーバー**: main プロセス内で `127.0.0.1` のみにバインド。選択フォルダをドキュメントルートとして配信。フォルダ変更・アプリ終了時に停止。
- **パストラバーサル拒否**: `../` 等でルート外へ出るリクエストは拒否。
- **Electron ハードニング**: `contextIsolation: true`、`nodeIntegration: false`。renderer からのファイルアクセスは preload 経由の限定APIのみ。
- **外部URL**: アプリ内で読み込まず、OS の既定ブラウザで開く。
- **MVPの実行境界**: 静的HTML/CSS/画像中心。HTML内JavaScriptの高度な実行保証、外部API通信、任意コード実行は対象外（後続検討）。

## 主要ユースケース

| ID | ユースケース | 成功条件 |
|----|--------------|----------|
| UC-01 | 仕様書フォルダを開いて1ページ目から読む | 目次1件目が表示され、一覧と同期する |
| UC-02 | ページ一覧から任意ページへ移動 | 該当HTMLが BrowserView に表示される |
| UC-03 | 目次のアンカー（`#section`）へジャンプ | 該当ページが開き、セクション付近へスクロール |
| UC-04 | 無効・範囲外・外部リンクを識別する | 一覧で状態が分かり、外部のみブラウザで開く |
| UC-05 | 目次なしフォルダを開く | 再帰スキャンでページ化し警告を表示 |
| UC-06 | キーワードで全ページ検索 | 右ペインにページ別ヒットが表示される |
| UC-07 | 検索ヒット間を前後移動 | ページ跨ぎで連続ナビゲーションできる |
| UC-08 | HTML内リンクで同一仕様書内を移動 | ビューワー内遷移し左ペイン選択が同期 |
| UC-09 | ズーム・集中モードで閲覧性を調整 | 操作に応じて表示が変わる |
| UC-10 | 最近使ったフォルダから再オープン | メニューから過去フォルダを選べる |

## 技術前提（参考）

- Electron + Vite + React + TypeScript
- UI: shadcn/ui（Base UI 版）
- 表示: React UI + `BrowserView`（`http://127.0.0.1:PORT/...`）
