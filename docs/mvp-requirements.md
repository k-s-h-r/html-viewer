# MVP要件定義 — HTML仕様書ビューワー

本ドキュメントは [product-spec.md](./product-spec.md) に基づくMVPの実装範囲・受け入れ条件を定義する。

## 機能要件

### FR-01 フォルダオープン

- ディレクトリ選択ダイアログで任意フォルダを開ける。
- 起動時の前回フォルダ自動オープンは行わない。
- メニューから最近使ったフォルダを選んで開ける。

### FR-02 目次解析とデッキ生成

- `index.html` を目次として解析し、**目次に載っているリンクのみ**をページとする。
- サブフォルダ内の `.html` も対象（例: `chapters/01-intro.html`）。
- `index.html` 自体はページ一覧に含めない。
- フォルダオープン直後、目次の1ページ目を表示する。
- ページタイトル: 目次リンクテキスト → `<title>` → 最初の見出し → ファイル名。

### FR-03 目次フォールバック

- `index.html` が無い、または目次リンクが0件の場合、配下 `.html` を再帰スキャンし自然順でページ化（`index.html` 除外）。
- 「目次がありません」警告を表示する。

### FR-04 リンク種別とページ一覧

- 左ペインに番号・ページタイトル・ファイルパスを表示（サムネイルなし）。
- 実ファイルなし → グレーアウト「見つかりません」、選択不可。
- フォルダ外 `.html` → グレーアウト「範囲外」、選択不可。
- 外部 `https://` → 「外部リンク」、選択時 `shell.openExternal()`。

### FR-05 アンカー付きリンク

- `page.html#section` は `page.html` と同一ページとして統合（重複排除）。
- ページ行をトグル展開し、目次上の `#section` を子項目として選択可能。
- 子項目選択時は `http://127.0.0.1:PORT/page.html#section` を開き該当箇所へスクロール。

### FR-06 仕様書表示（BrowserView）

- main が `127.0.0.1` のみにバインドするローカルHTTPサーバーを起動し、選択フォルダを配信。
- BrowserView は `http://127.0.0.1:PORT/...` を表示。
- フォルダ変更またはアプリ終了時にサーバーを停止。
- `../` 等によるルート外パスは拒否。

### FR-07 HTML内リンク遷移

- 表示中HTML内の同一仕様書内 `.html` リンクは捕捉しビューワー内で遷移。左ペイン選択を同期。
- 外部 `https://` は通常ブラウザで開く。

### FR-08 全ページ検索（カタログ）

- main が選択フォルダ配下HTMLを読み、ページ別ヒット件数・抜粋をメモリ上に構築。
- 大文字小文字区別は切替可能（デフォルト: 区別しない）。

### FR-09 ページ内検索（findInPage）

- 該当ページ表示後、`webContents.findInPage()` でハイライト・スクロール。
- カタログ検索と同一の大文字小文字設定を `matchCase` に反映。
- 独自DOM検索や `details.open = true` 等の手動展開は実装しない。

### FR-10 検索ナビゲーション

- 「次へ」「前へ」はドキュメント全体で連続。現ページの一致を辿り終えたら次ヒットページへ自動移動。
- 検索時のみ右ペインを開きページ別ヒット一覧を表示。
- 左ペインへのヒット件数バッジはMVPでは行わない。

### FR-11 ツールバーとページ移動

- 上部: 検索、ページ移動、ズーム、表示切替。
- `←` / `→` で前後ページ。

### FR-12 ズーム

- `webContents.setZoomFactor()` / `setZoomLevel()` をUIから操作。
- 拡大・縮小・100%リセットを提供。

### FR-13 表示切替

- サイドバー（ページ一覧）の表示 / 非表示。
- 集中モード（サイドバーと一部ツールバーを隠し仕様書表示を拡大）。

### FR-14 キーボードショートカット

| 操作 | ショートカット |
|------|----------------|
| 前 / 次ページ | `←` / `→` |
| 検索フォーカス | `Ctrl+F` |
| 次 / 前の検索ヒット | `Enter` / `Shift+Enter` |
| 拡大 / 縮小 | `Ctrl +` / `Ctrl -` |
| 100%に戻す | `Ctrl+0` |
| 集中モード解除 | `Esc` |

## 非機能要件

### NFR-01 セキュリティ

- Electron: `contextIsolation: true`、`nodeIntegration: false`。
- renderer のファイルアクセスは preload 経由の限定APIのみ。
- ローカルサーバーは `127.0.0.1` のみ。パストラバーサル拒否。

### NFR-02 アーキテクチャ

- React UI（一覧・検索・ツールバー）と BrowserView 表示を分離。
- ローカルサーバーは main プロセス内で稼働。

### NFR-03 技術スタック

- Electron + Vite + React + TypeScript。
- UI: shadcn/ui Base UI 版。

### NFR-04 パフォーマンス（MVP目安）

- 中規模仕様書（数十〜百ページ程度）で、フォルダオープン後に実用可能な応答性。
- 検索カタログはメモリ上構築（永続インデックス不要）。

### NFR-05 保守性

- `DeckPage`、`DeckToc`、`SearchHit` 等の型でデッキ・検索モデルを表現。
- リンク種別判定・フォールバック処理を共通化。

## 非対象（MVP外）

以下は MVP では実装しない。後続候補として扱う。

| 項目 | 備考 |
|------|------|
| 左ペインの検索ヒット件数バッジ | 右ペインに集約 |
| 起動時の前回フォルダ自動復元 | 最近使ったフォルダメニューのみ |
| 「幅に合わせる」ズーム | 拡大・縮小・100%のみ |
| HTML内JSの高度な実行保証 | 静的HTML/CSS/画像中心 |
| 外部API通信・任意コード実行 | 後続検討 |
| `display: none` や独自JSアコーディオン内の検索表示保証 | Find in Page 標準挙動のみ |
| 独自DOM検索、`details` 手動展開 | Chromium 標準に委ねる |
| コメント・レビュー・差分・発表者モード | — |
| PDF/PPTXエクスポート | — |
| `spec-index.json` / Markdown要約生成 | AI連携は後続 |
| 署名済みデスクトップ配布 | — |
| `manifest.json` によるページ順管理 | 目次HTMLのみ |

## 受け入れ条件

### AC-01 フォルダと目次

- [ ] フォルダ選択後、目次1ページ目が表示される。
- [ ] `index.html` はページ一覧に含まれない。
- [ ] 目次なし時、再帰スキャンでページ化し警告が出る。

### AC-02 ページ一覧

- [ ] 番号・タイトル・パスが表示される（サムネイルなし）。
- [ ] 無効・範囲外・外部リンクが仕様どおり表示・操作される。
- [ ] アンカー子項目選択で該当セクションへスクロールする。

### AC-03 表示とセキュリティ

- [ ] BrowserView が `127.0.0.1` 経由でHTMLを表示する。
- [ ] ルート外パス要求が拒否される。
- [ ] フォルダ変更・終了でサーバーが停止する。

### AC-04 検索

- [ ] 検索入力で右ペインにページ別ヒットが表示される。
- [ ] ヒット選択でページ表示と findInPage ハイライトが行われる。
- [ ] 次/前がページ跨ぎで連続動作する。
- [ ] 大文字小文字区別の切替がカタログと findInPage の両方に反映される。

### AC-05 ナビゲーションとUI

- [ ] HTML内同一仕様書リンクでビューワー内遷移し一覧が同期する。
- [ ] 外部URLが既定ブラウザで開く。
- [ ] ズーム・サイドバー切替・集中モードが動作する。
- [ ] 定義されたキーボードショートカットが機能する。

### AC-06 最近使ったフォルダ

- [ ] メニューから最近のフォルダを再オープンできる。
- [ ] 起動時に自動オープンしない。

## テスト観点

`sample-decks/basic/` を用いた手動確認を基本とする。

### 目次・デッキ

- 正常な `index.html` 目次から期待順序・件数のページが生成されるか。
- サブフォルダ内HTMLがページに含まれるか。
- タイトル推定（リンクテキスト / `<title>` / 見出し / ファイル名）の優先順が守られるか。
- 目次なし・空目次フォルダでフォールバックと警告が出るか。

### リンク種別

- 存在しないHTML、親ディレクトリ外HTML、外部URLが一覧上正しく区別されるか。
- 外部リンク選択でOSブラウザが開くか（モックまたは手動）。

### アンカー

- 同一 `page.html` の複数 `#section` が1ページに統合されるか。
- 子項目選択でURLにフラグメントが付きスクロールするか。

### ローカルサーバー・セキュリティ

- `127.0.0.1` 以外からアクセスできないこと。
- `../` 等のトラバーサル試行が拒否されること。
- フォルダ切替・終了でポートが解放されること。

### 検索

- 複数ページにまたがる語句でカタログ件数・抜粋が妥当か。
- 右ペインのみ開き、左ペインにバッジが無いこと。
- 現ページ末尾の次へで次ページ先頭ヒットへ移ること。
- 大文字小文字切替の一貫性。
- `details` / `hidden=until-found` 等標準HTMLは Chromium 任せで動作確認（保証外の `display:none` 領域は期待しない）。

### UI・操作

- レイアウト（左一覧・中央表示・上ツールバー・右検索）が仕様通りか。
- ズーム3操作、集中モードと Esc 解除。
- 全ショートカット表の操作。
- 最近使ったフォルダの記録と再オープン。

### 回帰の重点

- BrowserView と React 左ペインの選択状態同期。
- 検索ナビゲーション中のページ切替と findInPage の再実行タイミング。
