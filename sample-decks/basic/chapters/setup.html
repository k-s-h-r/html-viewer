第2章

セットアップ

仕様書フォルダの構成ルールと、ビューワーがコンテンツを安全に配信する仕組みを説明します。

  • カテゴリ: セットアップ
  • 対象: 仕様書の作成者

2.1フォルダ構成

入力単位は「1仕様書 = 1フォルダ」です。ビューワーはフォルダ直下の index.html を目次として読み込み、目次に載っているHTMLリンクだけを ページ一覧に並べます。サブフォルダ内のHTMLも対象です。 

basic/
├─ index.html        # 目次
├─ intro.html        # 第1章
└─ chapters/
   ├─ setup.html     # 第2章
   └─ search.html    # 第3章

2.2ローカル配信

選択フォルダは 127.0.0.1 にだけバインドしたローカルHTTPサーバーから配信されます。 外部ネットワークには公開されず、ルート外へ出るパスは拒否されます。

リンク種別の扱い
種別 挙動
フォルダ内 .html 有効なページとして閲覧できます。
実ファイルなし 一覧に「見つかりません」と表示し、選択不可になります。
フォルダ外パス 一覧に「範囲外」と表示し、選択不可になります。
https:// 外部URL 通常ブラウザで開きます。

注意 ../ などでフォルダ外を参照するリンクは安全のため無効化されます。 リンク先は必ず仕様書フォルダ内に配置してください。
