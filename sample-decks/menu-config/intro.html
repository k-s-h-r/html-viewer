パターン1

menu.json 目次

本デッキは パターン1: menu.json 優先 のサンプルです。 フォルダ直下の menu.json が最優先で読み込まれ、 index.html があっても目次には使われません。

1.1確認ポイント

左ペインのページ順が menu.json の定義どおりになっていることを確認してください。

  • 1番目: 検索（index.html では3番目）
  • 2番目: 概要（このページ）
  • 3番目: セットアップ（子項目 3-1, 3-2 付き）

1.2menu.json の形式

{
  "pages": [
    { "href": "chapters/search.html", "title": "検索", "num": "1" },
    { "href": "intro.html", "title": "概要", "num": "2" }
  ]
}

href は必須、title と num は任意です。形式は JSON を採用しています。
